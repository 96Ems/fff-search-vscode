UX decisions in this mockup

  • No banner, no dashboard. The root/status stays one quiet row.
  • Search input is primary; filters are secondary and collapsible.
  • Active mode is shown as chips, not heavyweight controls.
  • Text results optimize for scanning: file header, line number, monospace match line.
  • QuickPick uses location first, snippet second, directory last.
  • Actions stay hidden until hover to reduce visual noise.

Shortcuts proposed

  • /: focus current search input.
  • Ctrl+1: switch to Files.
  • Ctrl+2: switch to Text.
  • Ctrl+Left: collapse all text result groups.
  • Ctrl+Right: expand all text result groups.
  • Enter: open selected result.
  • Ctrl+Enter: open selected result to side.
  • Esc: clear search when input is focused.
