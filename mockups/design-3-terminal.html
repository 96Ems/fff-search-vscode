design notes — key decisions

  • fzf grammar throughout: ❯ prompt + blinking block caret, ❯ selection pointer column, 50/1738 counter with a dim rule line — everything monospace, flat, borderless rows.
  • Reversed path emphasis: directories in dim grey, filename bright + bold at the end; RTL-truncation keeps the filename visible when long paths overflow the 360px width.
  • All controls are inline text tokens (filters !build/ git:modified, mode tokens [files] [text], status toggles ◉ smart-case) — clickable, hover-underlined, zero chrome.
  • Text results mimic telescope/grep pickers: green file header with fold triangle + match count, then 539:22 │ code lines with the query bold-highlighted in bright cyan.
  • Mouse parity without breaking the aesthetic: hover reveals bracketed side/copy micro-actions pinned right; a keybar footer documents the keyboard path.
